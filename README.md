# r-course-learning-projects

This repository contains exercises, coursework, and small projects completed while learning R programming.

Topics covered so far (not all exercises are uploaded yet):
- Basic R syntax
- Variables and operators
- Loops
- Vectors
- Functions
- Basic statistical analysis
- Matrices
- Importing data
- Data Frames:
    - Basic operations
    - Filtering a data frame
    - qplot
    - building
    - merging   

The goal of this repository is to document my progress and build practical data analysis skills.
